CropOptima adalah capstone Bangkit Academy 2023 yang dikerjakan tim tujuh orang dari tiga jalur: Machine Learning, Cloud Computing, dan Mobile Development. Aplikasi Android-nya menyarankan tanaman berdasarkan lokasi dan kondisi tanah seperti nitrogen, fosfor, dan kalium, dengan memanggil model machine learning lewat API.

```flow
Aplikasi Android -> *Backend API -> Model ML (rekomendasi tanaman)
Backend API -> Cloud SQL
```

Saya berada di jalur Cloud Computing: membangun layanan backend yang menghubungkan aplikasi dengan model, lalu men-deploy-nya di Google Cloud dengan Compute Engine dan Cloud SQL.
