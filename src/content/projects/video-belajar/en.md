Video Belajar ("video learning") is an online course platform I built as the final project of the FullStack Developer Academy at Harisenin. It is a monorepo: a React SPA (Vite, Tailwind CSS, and Redux for state) on one side and an Express.js REST API with MySQL on the other.

```flow
*React SPA (Vite, Redux) -> REST API (Express.js) -> MySQL
```

Coming mostly from the backend, this project trained my frontend side: building pages in React, managing state with Redux, and wiring them to an API of my own.
