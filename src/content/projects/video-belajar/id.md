Video Belajar adalah platform kursus online yang saya bangun sebagai proyek akhir FullStack Developer Academy di Harisenin. Project ini berbentuk monorepo: SPA React (Vite, Tailwind CSS, dan Redux untuk state) di satu sisi, dan REST API Express.js dengan MySQL di sisi lain.

```flow
*SPA React (Vite, Redux) -> REST API (Express.js) -> MySQL
```

Bagi saya yang lebih banyak di backend, project ini melatih sisi frontend: menyusun halaman dengan React, mengelola state dengan Redux, dan menyambungkannya ke API buatan sendiri.
